H@N 433MHz LoRa Module Scanner

Browser flasher for the Elecrow CrowPanel ESP32 2.4" miner board with a wired Ra-01 / SX1278 radio

This build is only for one board: the Elecrow CrowPanel ESP32 2.4" "ESP32 Solo Miner LCD" (SKU DHM04624D) with an Ra-01 (SX1278) radio wired to it. Flashing replaces whatever is on the board now.

Flash it

  • Use desktop Chrome or Edge (they support Web Serial).
  • Plug the board in by USB-C, then click below and pick its serial port.
Your browser can't flash - open this page in desktop Chrome or Edge. This page must be served over https to flash.

What this build does

Two screens, switched with the tabs at the bottom. Meter shows the live signal level on 433.000 MHz with peak hold, the noise floor and a history graph. Sweep scans 430–440 MHz and draws a spectrum over a scrolling waterfall, so you can see what's transmitting nearby.

On the first start it asks you to tap four crosses to calibrate the touch screen (a stylus works best). The result is saved to the SD card and the board's flash. Hold BOOT for 2 seconds to calibrate again. If the radio isn't wired correctly, the screen says Radio NOT found.

Flashing failed, or want a clean slate?

Hold BOOT and tap RESET on the board to force the bootloader, then try again.
